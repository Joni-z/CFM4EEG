\section{Protocol notes and two corrections}
\label{sec:protocols}
\paragraph{Splits.}
TUEV: shared 16-channel bipolar cohort, 68,445 / 15,487 / 29,421 windows, 3,243 distinct test signals; validation once per epoch; $\kappa$ selects the checkpoint. TUSZ: official train / dev / eval, 10\,s windows, 46,091 test windows; validation every 200 steps, patience 20, focal loss. CHB-MIT: patient-disjoint, chb21 grouped with chb01 in training. IIIC: deduplicated, tie-free, patient-stratified split, 15,780 test rows. From-scratch baselines use each author's released training code with the shared arrays and documented input adaptations; BIOT and FFCL are reported at their validation-best checkpoint because their released entry point selects the terminal one. Pretrained baselines use released weights and each repository's preprocessing.

\paragraph{Correction 1: CHB-MIT evaluation composition.}
The legacy CHB-MIT validation and test sets contained 21,184 / 17,386 windows with 150 / 276 positives; the natural 10\,s grid has 21,094 / 17,224 windows with 60 / 114 positives. The extra 90 / 162 windows were seizure-centred. Test prevalence falls from 1.59\% to 0.66\%, and neither AUC-PR nor a validation-selected checkpoint is comparable across the two sets. All CHB-MIT numbers in the main text are labelled with the set they were scored on.

\paragraph{Correction 2: TUEV annotation multiplicity.}
TUEV's 29,421 test rows are 3,243 distinct signals, because the corpus annotates the same interval once per channel and the preprocessing cuts all 16 channels for every annotation; 144 identical-signal groups carry conflicting labels. No identical signal crosses the train / validation / test boundary. Weighting each distinct signal once changes magnitudes, not the ordering of the models compared in Section~\ref{sec:main}.

\section{Remaining experiments}
\label{sec:remaining}
In order: (1) finish the learned-row control on CHB-MIT (seed 2); (2) run the main model on all twelve corpora, three seeds, replacing the rotated-token stand-ins of Table~\ref{tab:main}; (3) under the main model, run the content three-arm (envelope only, waveform only, both) on TUEV, CHB-MIT, TUSZ and IIIC, three seeds; (4) run T1, T2 and T6 on synthetic signals and the T3 noise ladder on TUEV; (5) compare three-axis with a parameter-matched two-axis reader; (6) compare learned, fixed log-spaced and linearly spaced 16-band filterbanks, and 8 against 16 bands, three seeds; (7) re-train every model on the CHB-MIT natural grid and report that protocol only, with unique-signal weighting as a secondary TUEV metric; (8) re-run the pretrained baselines through the native pipeline and confirm or withdraw the single-seed Sleep-EDF and TUAR leads.
