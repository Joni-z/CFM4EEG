# CfFT and cross-frequency relationships

[Manuscript source](main.tex) · [references](references.bib) · [figure scripts](figures/src/) · [editable figure sources](figures/editable/)

This is the CVPR working draft of the PAC project. It describes the original CfFT tokenizer and the later standalone CFC measurement operator. Figures and tables reproduce the manuscript snapshot, including historical summaries whose uncertainty estimates have not all been verified against individual training runs. For reporting experimental measurements, use the [run records](../../experiments/README.md) and [matched studies](../../experiments/audits/README.md).

The figures directory contains the vector assets used by the draft and their sources. The three PowerPoint files cover the PAC illustration, the symbolic diagram and the architecture (slide 4 of the architecture deck). Compile the manuscript from this directory with `tectonic main.tex`.

[Earlier manuscript versions](../../docs/PROJECT_LAYOUT.md#historical-sources) remain available in Git history.
